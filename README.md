# Bufferbloat Tester

一个用于测试自有网络设备 Bufferbloat（缓冲区膨胀）和延迟变化的 Python 工具。

## 功能

- 显示当前系统、IPv4、网关、DNS 和可用网卡
- 支持选择本地网卡进行测试
- 支持 Windows、Linux 和 Termux
- 支持 Tkinter 图形配置界面
- 无图形环境时自动使用命令行向导
- 命令行配置中输入 `b` 可返回上一步
- 支持固定端口和端口范围
- 支持多种测试数据包类型
- 支持 Ctrl+C 安全停止测试并生成报告

## 运行

```bash
python C65.py
```

启动后可以选择：

- `Y`：使用 Tkinter 图形界面
- `N`：使用命令行配置
- 命令行配置中直接按回车使用默认值
- 输入 `b` 返回上一步

## 数据包类型

1. 随机数据（大包）
2. 全零数据（大包）
3. DNS 查询（短包）
4. NTP 请求（短包）
5. SSDP 发现（短包）
6. 混合模式

## 环境要求

只使用 Python 标准库，不需要安装第三方 Python 包。

Linux 图形界面需要 Tkinter：

```bash
sudo apt install python3-tk
```

Termux 推荐直接使用命令行模式。

## 注意事项

本工具会产生 UDP 测试流量。请仅对自己拥有或明确获得授权的设备和网络使用，并建议设置较短的测试时长、较少的线程数。

程序不会修改系统 IP、网关、DNS 或网卡配置。测试过程中可以使用 `Ctrl+C` 停止，程序会回收测试线程并输出结果。
